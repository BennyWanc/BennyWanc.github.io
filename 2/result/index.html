Part 1.1: Convolutions from Scratch

I wrote convolution with four loops, then used NumPy multiplication and summation to reduce it to two loops. Both versions flip the filter and use zero padding to keep the image size.

def convolve_four_loops(image, kernel):
    h, w = image.shape
    kh, kw = kernel.shape
    # adds zeros around the image
    padded = np.pad(image, ((kh // 2, (kh - 1) // 2),
                            (kw // 2, (kw - 1) // 2)), mode = 'constant', constant_values = 0)
    flipped = kernel[::-1, ::-1]  # Flip vertically and horizontally
    result = np.zeros((h, w))
    # select which pixels to calculate
    for y in range(h):
        for x in range(w):
            # goes to every filter weight
            for j in range(kh):
                for i in range(kw):
                    result[y, x] += padded[y + j, x + i] * flipped[j, i]
    return result

def convolve_two_loops(image, kernel):
    h, w = image.shape
    kh, kw = kernel.shape
    padded = np.pad(image, ((kh // 2, (kh - 1) // 2),
                            (kw // 2, (kw - 1) // 2)), mode='constant', constant_values=0)
    flipped = kernel[::-1, ::-1]
    result = np.zeros((h, w))
    for y in range(h):
        for x in range(w):
            # selects a region with the same dimensions in kernel
            patch = padded[y:y + kh, x:x + kw]
            result[y, x] = np.sum(patch * flipped)  # Replace the two inner loops
    return result

Part 2.1: Image Sharpening

A Gaussian blur keeps low frequencies. Subtracting it from the image isolates high-frequency detail, which I add back with strength α. I used a 13×13 Gaussian with σ = 2 and symmetric boundaries.

Larger α strengthens details but also noise and halos. I chose α = 1 for a moderate sharpening effect.

Blur, then sharpen again

Sharpening restores some edge contrast, but cannot recover the fine windows, foliage, and water texture lost during blur.
